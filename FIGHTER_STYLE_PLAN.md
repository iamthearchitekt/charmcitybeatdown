# Individual fighter styles — proposal for review

Spike and Chelsea now have the classic elemental specials described below. The remaining rows are proposals, not implemented moves. Keep the current costumes, likenesses, body proportions, Sega controls, and existing signature attacks. No medium attacks, strength variants, close/far normals, or cross-up system.

Implemented commands: Spike Live Wire = tap A or B three times quickly; Chelsea Flash Fire = Down, Down-Forward, Forward + A/B. Both are grounded attacks with normal interruptible startup and recovery.

Use A/B for punches, X/C for kicks, C for high kick, Y for throws. Each fighter should have one clear strength, one clear weakness, and two immediately understandable core specials. Existing additional signature moves stay available. New effects and animations must use each fighter's approved design reference; no whole-roster redraw.

For fighters receiving a new non-projectile style, replace an existing generic special rather than adding an ever-growing move list. Preserve specifically requested signature projectiles for Spike and Poe. Final input assignments and any projectile removals belong in the review of this plan.

Implementation order after review:

1. Establish Marcus, Vivian, and Eric as the balanced, fast-kick, and grappling benchmarks. Tune movement, startup, reach, recovery and damage first.
2. Add the remaining styles in small groups, inspecting each new pose against the approved neutral, face, hair, hands, clothing and KO reference before integration.
3. Update CPU decisions and the Sega-perspective pause move list per fighter. Clearly show what each special does and when it is risky.
4. Test both facings, blocking, whiffs, jump interactions, corners, throw escapes, KO follow-through and bonus-stage viability. Keep each style useful without giving anyone an unavoidable loop.

Art acceptance: slender smooth arms for women; existing men's physiques unchanged; consistent faces and hair; four fingers plus a thumb with natural occlusion; grounded KO on the back, face up, hands at the sides. Never alter the full sheet to solve a single bad frame.
